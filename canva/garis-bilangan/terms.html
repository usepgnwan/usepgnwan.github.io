Selamat datang di Garis Bilangan, aplikasi untuk Canva yang membantu siswa dan guru membuat visual garis bilangan yang akurat untuk materi bilangan bulat, persamaan linear satu variabel (PLSV), dan pertidaksamaan linear satu variabel (PtLSV). Dengan memasang atau menggunakan aplikasi ini, Anda menyetujui Syarat dan Ketentuan berikut.

Welcome to Garis Bilangan, an app for Canva that helps students and teachers create accurate number line visuals for integers, linear equations in one variable (PLSV), and linear inequalities in one variable (PtLSV). By installing or using this app, you agree to these Terms and Conditions.

1Tentang AplikasiAbout the App

Aplikasi ini memungkinkan Anda memilih topik materi (Bilangan Bulat: Penjumlahan & Pengurangan, Bilangan Bulat: Bandingkan & Urutkan, Persamaan Linear Satu Variabel, dan Pertidaksamaan Linear Satu Variabel), menulis soal, lalu melihat garis bilangan beserta langkah penyelesaiannya secara otomatis. Anda dapat mengatur semesta bilangan, skala sumbu, warna garis penyelesaian, titik bilangan, sumbu dan angka, latar belakang, serta font dari koleksi Canva, kemudian menambahkan hasilnya ke desain Canva. Garis bilangan yang sudah ada di desain dapat diperbarui kapan saja.

The app lets you choose a topic (Integers: Addition & Subtraction, Integers: Compare & Order, Linear Equations in One Variable, and Linear Inequalities in One Variable), type a problem, and automatically see the number line with its solution steps. You can set the number set, axis scale, solution-line, point, axis and number colors, background, and a font from Canva's collection, then add the result to your Canva design. Number lines already in a design can be updated at any time.
